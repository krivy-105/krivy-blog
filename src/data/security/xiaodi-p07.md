## 一、一句话总结这节课

**P6解决了"HTTP(S)怎么抓"，本集解决"不走HTTP的怎么办"：游戏、小程序、PC应用的私有协议流量，用科来/Wireshark这类全局工具从网卡按进程抓，锁定背后的服务器IP、域名、OSS资产；再用封包工具识别并重放游戏操作包（瞬移/攻击复现成功）——抓包的终点永远是资产信息，资产才通向下一步渗透测试。**

## 二、核心知识点

### 1. 开场定位与工具分工（00:00-02:26）
- 本集主题：**其他协议（非HTTP）的抓取**，覆盖APP、小程序、PC应用；没有Web应用——因为要抓的不是Web协议
- 工具二选一：**Wireshark**——安全圈用得最多、门槛高，全靠筛选语句，不用过滤语句就是一片凌乱；**科来（网络分析系统）**——门槛低，新手点鼠标就能用。按需选择
- 上一集的Burp/Charles只认HTTP(S)，这一集它们全程"下岗"

### 2. 前置认知：Burp为什么抓不到游戏（02:26-09:55）★理解前提
- 老师做了什么→现象→说明什么：
  - 逍遥模拟器装传奇类游戏"永恒雷霆"（下载77万次），Burp挂代理监听本机地址 → 先开模拟器浏览器：HTTPS立刻抓到 → **工具本身正常**
  - **代理开着进游戏→卡死在登录**（06:02-07:07）：客户端前期请求对代理敏感走不出去 → 正确姿势：**先进游戏再开代理**
  - 进游戏后打怪/聊天/移动：Burp里**零包**，换Charles同样零包（07:47-09:26）
- 结论：游戏通讯**不是HTTP协议**——不是工具坏了，是协议不对口
> ⚔️ 安全思维：抓不到≠没流量，先问"它走什么协议"——判断协议本身就是信息收集的第一步。

### 3. 科来抓非HTTP：选网卡+按进程筛（09:57-15:11）★核心操作
- 步骤：科来网络分析系统 → **选本机上网的以太网网卡**（直接从网卡抓全局流量）→ 开始 → **按进程过滤**，选逍遥模拟器进程 **MEmuHeadless** → 只看它的包
- 视图：IP端点/物理端点/协议分布；通讯对一目了然：本地随机高位端口（10301/11173）→ **114.67.23.67:8005，TCP协议**
- 现象→结论：114.67.23.67（广东·京东云）**一直在动**（他人消息、人物移动、系统提示），打怪瞬间流量暴涨（几百KB起步）→ **一直在动的那个IP就是游戏服务器**
- 延伸（14:42-15:11）：游戏被DDoS打崩的路径=先抓包拿到游戏服务器IP→对IP打流量攻击
> ⚔️ 资产收集不用先扫：让目标自己跑两分钟，"哪个IP在动，哪个就是服务器"。

### 4. Wireshark对照（15:12-17:55）
- 同样抓以太网网卡，114.67.23.67也能看到 → 工具都能抓
- 区别：Wireshark抓**全机所有流量**，不知道哪包属于模拟器，要靠display filter自己判断；优势是专业性强、可拆包分析。科来按进程/端点点选即得，重"抓与展示"，Wireshark重"拆与析"
- 定位（17:16-17:51）：非专业快速拿资产→科来；后期专业流量分析→Wireshark
> ⚔️ 两工具互补：科来定位，Wireshark深挖。

### 5. 小程序抓包：WeChatAppEx进程（18:23-35:40）
- 汽车之家小程序（19:03-20:15）：科来按进程筛**WeChatAppEx.exe**（微信小程序运行进程）→ 域名/IP站点全是汽车之家的；筛HTTP(S)可列出访问过的全部HTTPS域名——"小程序必须转发联动才能抓"的说法被打破
- 欢乐斗地主（hlddz.qq.com）（20:20-30:06）：Burp/Charles只抓到登录等HTTPS包，**打牌聊天零动静**；换科来按进程抓→数据随操作持续增长，能抓到（服务地址为域名形式）
- 例外（30:51-31:31）：本地机器人陪玩、资源（头像等）已打包在本地 → 无网络交互，抓不到属正常
- 羊了个羊（32:24-35:30）：先Charles确认HTTPS能抓 → 科来对比：抓的差不多（它本身走HTTPS），仅点击触发时多出一个IP站点
> ⚔️ "抓不到"三连排查：协议不对口？功能没触发？资源在本地？

### 6. 封包监听与重放（35:41-42:32）★本集高光
- 工具：封包截取工具；设置：**只显示发送包**（本地→服务器；收包是服务器发你的，意义不大）+ 关联模拟器进程
- 交叉验证（37:29-38:51）：登录瞬间几个包出去 → 目标114.67.23.67，与科来结果完全一致（本地11173→目标8005）→ 双工具互证服务器IP
- 心跳（39:32-39:55）：人物不动只有心跳包维持在线；一移动包量暴增 → **每个操作=一组数据包**
- 重放实验（40:05-41:42）：
  - 瞬移：正常通讯包值恒为"1"，点随机瞬移后出现"2"的包 → 选中→发送 → **游戏画面再次随机瞬移**
  - 攻击：砍一刀出现"25"号包 → 重发 → 动作复现
- 说明：通讯包=操作指令，识别"触发事件包"后重发即"重复操作"——**这就是外挂封包重放的原理**
- 安全视角（42:12-42:54）：渗透抓封包不为刷装备，为看**通讯流程+远端IP**，114.67.x.x才是想要的
> ⚔️ 封包重放=TCP层的重放攻击：服务端不校验时序/次数/来源，客户端指令就能无限重演——和Web重放攻击同一个思想。

### 7. 从服务器IP到资产（42:33-44:36）
- 游戏服务器在京东云（广东）→ 对**8005端口**尝试信息收集 → 主机上还开着4389等端口/接口服务
- 游戏域名（VANGUS）→ whois反查注册公司（北京某游戏公司）→ 域名下资产众多 → **下一步安全测试就在这些资产上做**
- 至此完成"APP脱壳"：抓包跳出App本身，接入Web/端口渗透的循环
> ⚔️ 抓包产出=资产清单（IP/域名/端口/OSS），资产清单=渗透弹药库。

### 8. PC应用抓包+包能不能测（44:48-50:19）
- 斗鱼直播伴侣、腾讯会议、微信：科来**对进程监控**即拿到提供服务方的域名/IP → PC端抓包就这么简单（47:22-47:32）
- 数据包能否测试的两类分法（47:47-50:19）：
  - HTTP(S)类 → 丢Burp做Web安全测试
  - 非HTTP类 → **不可能提交给Burp**（它只认Web协议）；科来自带**数据包生成器**可构造发送，但非HTTP包结构复杂，改错即死，且包大多已加密
- 实战原则：非HTTP应用**抓到域名/IP就足够**，从IP与资产层面继续下一步
> ⚔️ 测试面收敛：Web测包，非Web测端口与服务——精力花在能测的地方。

### 9. 测试全景：渗透角度 vs 逆向角度（50:37-58:03）
- 渗透角度（本课）：抓包→资产（IP/域名）→测资产上的服务（Web服务、端口服务：数据库、第三方软件）与接口（API、APP引用的OSS资源/存储空间）
- 逆向角度（APP章节展开）：①反编译源码找资产、泄露的配置地址与**API配置Key**；②纯逆向看产品设计逻辑：不规范加密、可绕过策略、删验证重发包→绕过验证；PC软件逆向同理，以APP居多
- 本课抓包唯一目的：**提取资产信息**——资产不明确，安全测试无从谈起
- 抓不全的真相（55:41-58:03）：不是没包，是**没触发**——页面不点开就抓不到；抓全要"模拟点击遍历"（仅APP可做，APP章节讲）
> ⚔️ 安全国三条线：Web改包、主机端口渗透、移动逆向找Key——抓包是三条线的共同入口。

### 10. 实战加餐：小程序OSS资产（59:00-64:54）
- 应弹幕要求演示某视频类小程序（课程代号"小公主"，上期P6的"贵妃"同源）：科来中途跑崩换工具续抓 → 香港服务器在提供服务+多个域名
- 关键收获：抓到**阿里云OSS**——小视频/图片全存桶里；若能拿到OSS的Key（AK），登进去资源全带走（APP章节演示反编译拿Key绕会员）
> ⚔️ OSS泄露=云存储未授权访问：抓包见到OSS域名别放过，Key一旦到手，桶里全是资源。

### 11. 收尾与答疑（67:41-76:35）
- 抓不到场景板书（67:51-68:44）：**抓不到/一抓就死/一抓就卡/崩溃**=检测防护（加固、证书校验等），APP最常见，PC应用几乎没有；绕过在APP/小程序章节讲
- 工具答疑：入门用科来足够；Wireshark在蓝队课程单独讲（流量分析+筛选语法，专门有整本书讲它）；发包可以
- Burp激活答疑（70:29-74:09）：打不开=Java环境问题；激活工具须**命令行在Burp目录下运行**（放C盘根目录=路径错），出界面后填License Key；不行就公众号搜最新激活教程
