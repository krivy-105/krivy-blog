# 正文标题

正文用标准 Markdown 写就行，和文章页一样支持：

- 表格、引用、代码块、任务列表
- `行内代码`、**加粗**、[外链](https://example.com)
- 图片：`![说明](/uploads/xxx.png)`

## 代码块示例

```bash
nmap -sV -T4 192.168.1.0/24
```

## 表格示例

| 参数 | 说明 |
|---|---|
| `-sV` | 探测服务版本 |
| `-T4` | 加速扫描 |

## 使用说明（复制这一整段改就行，写完删掉注释）

1. **文件名**：`NN-简短名字.md`，比如 `01-SQL注入基础.md`。
   以 `_` 或 `.` 开头的文件**不会**出现在列表里，可以拿来放草稿。
2. **slug**：建议英文，短一点，会出现在网址里：`/security/你的slug`。
   不写就用文件名（中文名会让网址变成一串百分号编码，不好看）。
3. **category**：列表页的筛选按钮是按它自动生成的，取值随意但要一致，
   比如：`CTF`、`Web安全`、`逆向工程`、`密码学`、`内网渗透`、`工具配置`、`靶场笔记`。
4. **tags**：逗号分隔的数组，会渲染成小标签。
5. **date**：`YYYY-MM-DD`，列表按它倒序排（新的在上面）。
