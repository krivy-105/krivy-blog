# 网安笔记区

这里放网安方向的学习笔记、实验记录与工具备忘——**加密、渗透、逆向、CTF、靶场**这类内容会集中收在这个栏目里，不和「技术博客」区混着。

## 为什么单独开一个栏目

文章区（`/blog`）是**数据库驱动**的：要登录、要审核、有标签、有点赞评论。适合"写成一篇给人看的文章"。

而这个栏目是**文件驱动**的：文档就是仓库里的 `.md` 文件。适合"边学边记"的原始笔记——不需要排版得很完美，扔进去就能看。

| | 文章区 `/blog` | 网安笔记区 `/security` |
|---|---|---|
| 存放方式 | SQLite 数据库 | Markdown 文件 |
| 发布方式 | 后台写作 + 审核 | 提交文件后自动上线 |
| 适合 | 成体系的文章 | 学习过程、实验记录 |
| 互动 | 点赞 / 评论 / 收藏 | 无（专注阅读） |

## 新增一篇文档

只需要三步：

1. 在 `src/data/security/` 新建一个 `.md` 文件，文件名的开头别用 `_`
2. 按 `_模板.md` 的格式写上 frontmatter（`title` / `slug` / `category` / `tags` / `summary`）
3. 提交推送——部署完成后它就会出现在这个页面

## 写法约定

- **`slug` 建议用英文**：它会进网址（`/security/你的slug`）。用中文的话网址会变成百分号编码，分享出去不好看。
- **`category` 要保持一致**：页面顶部的筛选按钮就是按它自动生成的，同一个方向尽量用同一个词。
- **`date` 决定排序**：列表按日期倒序，新的在上面。

> 下划线开头的文件（比如 `_模板.md`）和草稿不会出现在列表里，可以放心丢在同一个目录。
